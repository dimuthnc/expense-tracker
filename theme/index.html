How a change reaches production

Three gates, no exceptions

1 Intent 1 / 3

A person writes down what should change and why it matters to the customer. No ticket moves without that second half.

2 Build and prove 2 / 3

Contract tests, replayed production traffic, and a reconciliation run against yesterday's ledger. The pipeline is allowed to be slow. It is not allowed to be quiet.

3 Release 3 / 3

Canary on one corridor, watched for a full settlement cycle before it widens. Rollback is a button, not a runbook.
